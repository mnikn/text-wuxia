# 手玩脚本：物品与负重

本批（物品系统）不写内容侧自动化测试（见 grilling 决议：验收方式定为人工核对），开场链的正确性靠这份脚本。
**每次改动 `src/content/twee/` 下的开场链，或改动物品表 `src/content/items.ts` 与 `SLICE_TUNE.carryMax`，都要照着走一遍。**

前置：`npm run dev`，打开 dev 地址，点「从头开始」。窄栏入口要把窗口收窄到 900px 以下（或点折叠箭头）才看得到。

## 一、主线：取剑 → 当剑 → 抓药 → 买粮 → 回家 → 歇下

| # | 操作 | 期望读数（侧栏 / 行囊 / 正文） |
| --- | --- | --- |
| 1 | 开局静置 | 银钱 0 文；行囊空、负重 0 / 20 斤；正文写「灶上的药罐空了三天」；选项只有「观察墙上的剑」「观察米缸」 |
| 2 | 观察墙上的剑 | 出父亲那把剑的三段正文；该观察选项消失 |
| 3 | 把剑取下来 | 行止记录「剑 +1」；行囊 剑 1 件 · 3 斤，负重 3 / 20；回村正文写「剑裹在布里，你拎着」 |
| 4 | 前往南门贫巷 → 前往当铺 | 当铺出现「当剑」；此时没有「前往济生堂」 |
| 5 | 当剑 | 记录「银钱 +1 两」「剑 -1」「当票 +1」；银钱 1 两；行囊里剑没了、当票 1 件（不计重），负重 0 / 20 |
| 6 | 返回 → 前往济生堂 → 抓药 | 记录「药包 +1」；银钱 700 文；负重 1 / 20；结果屏末尾不再出现写死的钱数 |
| 7 | 前往市集 → 买一星期的粮 | 记录「米袋 +1」；银钱 500 文；负重 16 / 20（余 4 斤） |
| 8 | 前往官道 | 正文「怀里揣着钱，肩上压着粮袋。」「怀里还揣着那七剂药。」「空的是那双手，剑已经不在了。」 |
| 9 | 前往城郊家村 | 回村正文走「已在城里转过」那一支：母亲坐在门槛上择菜、「娘，药抓回来了。」；选项是「回屋歇下」「前往南门贫巷」 |
| 10 | 回屋歇下 | 记录「药包 -1」（药交到母亲手上），负重降到 15 / 20；落到「现在可以开始行动了。」（本批到此为止） |

## 二、软锁路径（必须能再进城）

这是物品化改造最容易踩的坑：出口条件若读「身上有没有剑」，当完剑就回不了城，家门外会变成一条死路。

1. 观察剑 → 取剑 → 前往南门贫巷 → 当铺 → 当剑 → 返回
2. 前往南门贫巷 → 前往城郊家村
3. 期望：家门外**不是**死路，选项里必须有「前往南门贫巷」；正文走「回来了？」那一支（母亲没回头、灶上的药罐还空着、墙上那处空着）；行囊里只有当票，负重 0 / 20
4. 再进城买一趟粮回来，期望正文换成「母亲坐在门槛上择菜」那一支

## 三、只买粮没抓药

1. 取剑 → 当剑 → 南门贫巷 → 市集 → 买粮 → 前往官道
2. 期望官道正文里**没有**「怀里还揣着那七剂药」这一句，其余照旧

## 四、只抓药没买粮

1. 取剑 → 当剑 → 南门贫巷 → 当铺 → 前往济生堂 → 抓药 → 前往城郊家村
2. 期望家门外走「回来了？」那一支：母亲没回头、灶上的药罐还空着、墙上那处空着，并多出「你把药包搁在灶沿上。她看了一眼，没伸手。」
3. 期望选项里有「前往南门贫巷」，**没有**「回屋歇下」（身上没粮）
4. 期望行囊是 药包 1 件 + 当票 1 件，负重 1 / 20

## 五、行囊弹框

- 侧栏底部的「行囊」按钮、窄栏的「行囊」按钮都能打开居中弹框；点弹框外面、右上角 × 、Esc 都能关
- 清单只列身上有的东西；空手时写「身上空着。」
- 当票 0 斤，不进负重（与银钱一样不占分量）
- 关掉行囊再选选项，读数要跟着一起变

## 六、本批不看的

装备与 `equip()`、使用物品（吃药回体力）、存档层、膂力派生上限。这些都不在范围内，看到缺它们属正常。
