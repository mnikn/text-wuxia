# 手玩脚本：开场与谋生

内容不做自动化测试（规范：`tests/` 只测机制、夹具用内联中性数据，内容改动不该弄红测试），开场链与谋生循环对不对全靠这份脚本人肉走一遍。
**每次改动 `src/content/twee/` 下的开场链或石桥镇，或改动物品表 `src/content/items.ts`、`SLICE_TUNE`，都要照着走一遍。**

前置：`npm run dev`，打开 dev 地址，点「从头开始」。窄栏入口要把窗口收窄到 900px 以下（或点折叠箭头）才看得到。

## 一、开场链：取剑 → 当剑 → 抓药 → 买粮 → 起火

| # | 操作 | 期望读数（侧栏 / 行囊 / 正文） |
| --- | --- | --- |
| 1 | 开局静置 | 银钱 0 文；行囊空、负重 0 / 20 斤；正文写「灶上的药罐空了三天」；动作只有「观察墙上的剑」「观察米缸」 |
| 2 | 观察墙上的剑 → 收回目光 → 把剑取下来 | 行囊 剑 1 件 · 3 斤，负重 3 / 20；门外地点只有「前往村中心（两刻）」——**「前往石桥镇」家里永远没有**，也没有任何恢复类动作 |
| 3 | 前往村中心 | **耗两刻**；时辰从辰时正走到辰时二刻；正文是村中心的十字街口；出口为当铺 / 济生堂 / 市集 / 回家（两刻）——**此时没有「前往石桥镇」** |
| 4 | 前往当铺 → 当剑 | 行止「失去了剑，获得了 1 两银两、当票」；银钱 1 两；行囊里剑没了、当票 1 件（不计重），负重 0 / 20 |
| 5 | 前往济生堂 → 抓药 → 前往市集 → 买粮 | 药包 +1（银钱 −300 文）、米袋 +1（银钱 −200 文）；负重 16 / 20（余 4 斤）；银钱 500 文；店内互达不耗时。**药与粮本批各只能买一次**：煮过饭药（`故事.开场.煮饭熬药` 走过后）两处选项都不再出现 |
| 6 | 前往村中心 → 回家 → 起火煮饭和药 | 回家耗两刻；行止「失去了药包、米袋」；落到开场收尾，**分三屏走**：`故事.开场.煮饭熬药`（收碗起话头）→ `故事.开场.谋生打算`（「我去石桥镇找活做」／母亲「那是八个时辰的路，一天走不到」／「到了镇上，我先寻个落脚处住下。白日找活，挣够了钱再回来。」）→ `故事.开场.辞行`（母亲「路上当心，别跟人置气。」，收在「前往石桥镇的路需要先经过村中心。」） |
| 7 | 继续 → 前往村中心 | 门外正文换成结算后那一支（「灶上还温着药渣」，不该再出现「药罐空了三天」）；再到村中心，**此时才出现「前往石桥镇（八个时辰）」** |
| 8 | 观察米缸 | 随时可看（看过一次即消失）；身上有米袋时写「新买的米袋靠着缸边，袋口扎得紧」，没米时写「缸身歪着靠在墙根，刮不出一把米」 |

## 二、谋生循环：石桥镇日结（只能从村中心去）

| # | 操作 | 期望读数 |
| --- | --- | --- |
| 1 | 村中心 → 前往石桥镇 | **耗八个时辰（64 刻）**；地点读数变「石桥镇」；正文按到达时辰分两支：白天「街上人正多」，夜里「街面上已经静了，只有粮栈和酒铺还点着灯」；动作「应下这趟活（一个时辰）（耗体力 20）」、地点「前往村中心（八个时辰）」 |
| 2 | 应下这趟活 | 银钱 +30 文、体力 −20、时间 +一个时辰；结果屏「直起腰」 |
| 3 | 直起腰 → 再应下这趟活 | 活还在（保底谋生可无限重复，不设每日上限）；银钱再 +30 |
| 4 | 问这粮是往哪里去的 | 不耗时（即时动作），就地追加一段牙子的回话，时钟不动；**此后再不出现**（问过粮船） |
| 5 | 前往村中心 → 回家 | 回程也是八个时辰，到家再两刻；到家落回结算后那一支 |
| 6 | 药粮见底之后 | **本批没有第二次采买**：煮过饭药之后，济生堂与市集的买入选项都不再出现（等下一批接补给与开销）。所以钱目前只进不出——挣到的那点钱还没有去处 |

**一趟来回**：家里 → 村中心（两刻）→ 石桥镇（八个时辰）→ 回村中心（八个时辰）→ 家（两刻）≈ 十七个时辰。只扛一次货是亏的，通常要连扛数趟再往回走。镇上没有落脚处，家里也没有恢复入口——**体力是本批唯一的硬约束**，见下一节。

## 三、软锁与边界（必须逐条点过）

1. **村中心身无分文、身上无货**：出口里必须有「回家（两刻）」，不能只剩三处铺子（旧版这条会卡死）。
2. **本批没有任何体力恢复入口**（有意为之，恢复入口随睡觉/吃饭一起做）：家门外只有「观察」与出行。体力不足 20 时「应下这趟活」应显示为不可选并说明原因（体力不支）——这是当前版本的已知代价，看到属正常，不是 bug。
3. **镇口门槛与唯一入口**：「前往石桥镇」只在**村中心**出现、且要走过开场收尾（煮过饭药）之后；家里门外与镇上都没有这个出口。
4. **负重**：身上已有米袋（15 斤）时再买一袋，应被负重硬门拦下。

## 四、本批不看的

体力恢复入口（睡觉、吃饭、镇上歇脚）、药钱周结与欠款（母亲软压力结算）、昼夜节律、镇上除牙市之外的设施（客栈、食肆）、涌现素材、存档层。看到缺它们属正常。
