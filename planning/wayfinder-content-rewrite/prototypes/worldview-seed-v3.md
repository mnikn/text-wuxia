## 1. 时代底色（同 v2，未驳回）

架空乱世，天子失鹿、节帅林立（五代十国气象）：兵祸连年，铜钱贱、谷帛贵，流民塞道。无中央权威——官府弱而横、军队即法度、门派帮会是普通人抓得住的少数"组织"。武人吃香：护运、剿匪、军前效力，皆是刀头舔蜜的活钱。

## 2. 县城：洺川县（未驳回）

东面**彰义军**、西面**武泰军**两镇拉锯地带的下县。城小墙旧，驻一营弱厢兵，谁过境都征一遭。市面靠过兵经济与江湖生意撑着，官道渡口是商路咽喉。

## 3. 门派：苍岩派（金庸式，重写）

山门在城外苍岩山上，县城南街设**苍岩别院**，是对外的门户。乱世里正经门派也要吃饭：**护镖护运**（乱世商路险，镖业反盛）、**受雇军前**（教习、护卫、斥候）、**剿匪收赏**、**富户护院**——山上有师承规矩，山下靠武艺营生。

收人三样：**资质验看**（武功根底）、**保人引荐**（江湖交情）、**行止具结**（品行信用——乱世卷款潜逃的太多）。气质：江湖正道路数，"学武先学做人"；但乱世逼人，别院接的差事未必都干净，这正是张力的来源。

## 4. 身份链（等价"游子→候选学徒→记名弟子"）

**白身**（无籍贫家子，工钱日结）→ **别院学徒**（管饭宿、习武攒保人，无工钱）→ **苍岩记名弟子**（挂名接差，见差钱，抽成奉师门）。

## 5. 属性体系（待定 · 参考北大侠客行天赋）

原"成长型三维"（身技/人情/心志）被用户驳回，指定参考北大侠客行（pkuxkx）天赋体系：**膂力 / 身法 / 悟性 / 根骨 / 福缘 / 容貌**，角色创建时先天分配、后天靠武功技能成长（"郭靖式"低天赋也能成大侠）。传统语义：

| 天赋 | 传统作用 |
| --- | --- |
| 膂力 | 进攻伤害、负重、外功底子 |
| 身法 | 速度、闪避、轻功 |
| 悟性 | 学武速度、读书、招式领悟 |
| 根骨 | 体力/内力恢复、承受伤害、内功潜质 |
| 福缘 | 奇遇概率、运气性检定 |
| 容貌 | NPC 初见反应、部分剧情 |

**融合结构三案（待用户确认）**：

1. **先天天赋 + 后天技能双层**（贴北侠原味）：先天分配天赋（不可练），后天成长全在技能层——武功等级（拳脚/刀剑/轻功…）与社会技能（口才/阅历/定力…）。检定 = 相关天赋 + 技能等级。入门三证明改挂技能或天赋。
2. **单层可成长**：只取侠客行词作成长属性，无先天/后天分层；"悟性/福缘可练"语义需换词消化。
3. **双层不拆技能**：先天战斗向天赋（膂力/身法/根骨）+ 人情/心志保留为成长属性，不引入技能层。

**维度取法**（配合任一结构）：五维（弃容貌）/ 六维全取 / 三维战斗向。

## 6. 核心张力（同 v2 结构，门派代入苍岩）

两镇暗斗 × 苍岩别院两头接差：彰义、武泰都在洺川埋人，别院的镖与差两边钱都收——护的货可能是东家军械，押的赃可能是西家赃产。接差越深，卷得越狠。私线：母亲的药钱。

## 7. 开场节奏（等价"七日入门"；母亲=软压力）

- **周结药钱**（短期循环）：药每周一结，断药则病情恶化（恶化只是损失与剧情，不是必然死亡）。首批数值：一星期的药 300 文，一星期的粮 200 文。
- **攒大钱续命**（中期目标）：名医药资/疗程是显性金钱目标；花到位病情进入长期稳定。
- 入门三证明：资质验看 / 保人引荐 / 行止具结。
