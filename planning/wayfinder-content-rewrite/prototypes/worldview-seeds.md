# 世界观候选种子（PROTOTYPE · 三套并排，选歪一套后逐段打磨）

- 对应票据：[起草并选歪新世界观候选种子](https://github.com/mnikn/text-wuxia/issues/14)
- 日期：2026-09-15
- 用途：一次性反应材料。选歪后本文件降级为参考，定稿写入正式设定文档。
- 统一骨架（票面锚定物清单）：县城气质与地理完型 / 门派生态 / 身份链（三级，等价"游子→候选学徒→记名弟子"）/ 属性词汇（三维，等价"体质/人望/心性"，供检定与成长）/ 核心张力 / 开场节奏（等价"七日入门"）/ 地点表（≈8 节点）/ 具名人物原型（≈6）/ 文风样本（3 段，决定正文腔调）。
- 引擎兼容性预设（三套通用，不随选歪变化）：入门证明三类等价物、检定档带 ±20、失败延续、地点节点 + 时间成本。属性三维各自映射检定（身技/人情/心志各一）。

## 套一 · 漕烟（水陆码头县）

**一句话**：漕运末端的湖口县，跟着一条船混饭吃，混进护漕的行会门派。

| 项 | 内容 |
| --- | --- |
| 县城 | **湖口县**：漕河入湖处，官仓、牙行、码头三足鼎立。湿、吵、钱味重；四季漕汛定节奏。 |
| 门派 | **澜庭**：护漕起家的行会式门派，半武馆半帮口。收人看水上功夫与信义，堂内派系分"护航派/靠岸派"。 |
| 身份链 | 浮浪儿（投亲无着、滞留码头）→ 挂名桨手（有人作保，随船当差）→ 澜庭执牌（正式执事，接护货差事）。 |
| 属性 | **水性**（身技：泅渡、操舟、桅上功夫）、**手面**（人情：打点、斡旋、市面脸熟）、**胆气**（心志：夜航、对峙、沉船时先救人还是先救货）。 |
| 核心张力 | **漕粮折色案**：官仓以陈粮折新粮，账面亏空；湖匪劫的每趟货都像有人在里应外合。护一趟货 = 趟一次浑水。 |
| 开场节奏 | **十日漕汛**：汛期内谋得一个桨位（等价"七日入门"）；三条证明路径——水勇（救场/护航）、保人（牙行或船头引荐）、行止（还债/守约）。首次任务 = 押一趟敏感货过湖。 |
| 地点表 | 码头（讨生活）、湖神庙（落脚）、南市（买卖）、官仓外（差事）、船板街（酒饭住宿）、芦苇荡（野外/险）、对岸渡口（远端）、澜庭分堂（门派驻点）。 |
| 人物原型 | 船头把式（引路人，粗中有细）、牙行娘子（保人路径，精明）、老桨手（师父，守旧）、巡湖皂隶（官面，可收买）、湖匪眼线（潜伏敌）、澜庭堂主（终审者）。 |
| 失败延续 | 货沉赔债、船籍被扣、被人情套牢、湖匪记名——都写回码头生存循环。 |

**文风样本**：

> 漕河在五更头最响。你枕着船板听水拍帮，一船人只有你睡不着——桨位的事没落定，谁睡得着。
>
> 牙行门口挂灯未熄。娘子的算盘停了停：“湖口县不养闲人。要么三日内有船头替你担保，要么趁汛前盘缠还够，出城投别处去。”
>
> 芦苇荡里横着半截桅杆。老桨手啐了一口：“昨夜又一条。官面上说是风。风会把货舱劈得这么齐整？”

## 套二 · 塞声（边地军镇）

**一句话**：军镇改县的靖北堡，在马市与烽燧之间找个活法，考进戍边的枪棒世家。

| 项 | 内容 |
| --- | --- |
| 县城 | **靖北堡**：撤卫改县的前军堡，边墙、马市、屯田三方挤压。风沙大、军纪余威、胡汉杂处；昼市夜禁。 |
| 门派 | **朔锋堂**：戍边枪棒世家，半军半民，祖上出过把总。收人看膂力与守令，堂训"枪不问出身，问令行不行"。 |
| 身份链 | 流户（逃荒/逃债入边）→ 伴役（随军杂役，领半饷）→ 朔锋堂候补（考校后随队历练）。 |
| 属性 | **膂力**（身技：枪棒、负重、土木）、**眼线**（人情：番话、市口打听、边贸门路）、**守令**（心志：军令、忍耐、站桩守夜）三维。 |
| 核心张力 | **马市私盐与烽燧虚报**：边军吃空饷、烽燧报平安换市赏；商队走的黑道与军械流向对不上账。随一次哨探 = 摸一次老虎屁股。 |
| 开场节奏 | **半月边禁轮回**：下轮开禁前谋得军籍或堂口候补（等价"七日入门"）；三条证明路径——武备（较艺/捕谍）、军保（伍长或把式作保）、行伍名声（守夜/还粮）。首次任务 = 随一队哨探押送密件。 |
| 地点表 | 南马市（讨生活）、流户窝棚（落脚）、堡内街（买卖）、教场（差事/训练）、烽燧哨线（野外/险）、黑河道（远端）、朔锋堂（门派驻点）、税课司（官面）。 |
| 人物原型 | 老伍长（引路人，一身旧伤）、马市牙侩（保人路径，胡汉通吃）、堂口枪棒教习（师父，严）、巡堡夜不收（官面，多疑）、走私头目（潜伏敌）、朔锋堂主母（终审者，当家的是寡嫂）。 |
| 失败延续 | 军棍与罚役、断饷负债、市口拉黑、边禁被困——都写回堡内生存循环。 |

**文风样本**：

> 风从边墙上来，刮得马市的幌子啪啪响。你把最后半张饼掖回怀里。堡里管这叫"开饭风"——风一起，市就散，市一散，今天的工钱就没了。
>
> 老伍长蹲在教场边看新丁扎枪。他没看你，只把下巴朝沙地一点："站过去。站到换岗。站得住，明日起你领半饷。"
>
> 烽燧上第三道烟起了。夜不收眯眼数了数，骂了句谁也听不懂的话："又报平安。平安个鸟——黑河道昨夜过了三百匹马。"

## 套三 · 雾涧（山中原县）

**一句话**：群山夹着的涧口县，替山里人背盐送货，拜进半僧半道的护矿山门。

| 项 | 内容 |
| --- | --- |
| 县城 | **涧口县**：两山夹一涧，山货集散与私盐孔道。雾重、封闭、宗族把持；外来人永远带着"山外"标签。 |
| 门派 | **云隐岩**：半僧半道的山门，矿工护矿起家，岩上练功岩下背盐。收人看脚力与心性，"进岩先背三年盐"的旧规已松。 |
| 身份链 | 逃户（避役/避债入山）→ 挂单苦力（庙产挂单，背盐还食宿）→ 云隐岩记名（记名后随队走盐道）。 |
| 属性 | **脚力**（身技：负重、攀爬、识路）、**山话**（人情：方言、山规、宗族脸熟）、**狠劲**（心志：狠与忍——狠得下手，忍得住气）。 |
| 核心张力 | **盐道改宗**：官府改盐引归并，老盐道要断；岩上要护吃饭的路，县里要立新法。走一趟盐 = 在两头的账上各记一笔。 |
| 开场节奏 | **一旬雾季**：雾散前谋得挂单与记名（等价"七日入门"）；三条证明路径——脚程（背盐/救场）、岩保（执事或宗亲引荐）、山誉（济困/守信）。首次任务 = 雾季末护一趟"两头都不认账"的盐。 |
| 地点表 | 涧口集市（讨生活）、山王庙（落脚）、岩下盐仓（差事）、雾道（野外/险）、矿村（远端/人情）、云隐岩（门派驻点）、县衙税房（官面）、货栈茶棚（消息）。 |
| 人物原型 | 背盐把头（引路人，话少秤准）、庙祝老道（保人路径，装糊涂）、岩上教习（师父，只教忍）、税房书办（官面，贪而小心）、私盐枭首（潜伏敌，山里有人）、岩主（终审者，十年不下一岩）。 |
| 失败延续 | 盐损赔役、庙籍被逐、宗族结怨、雾道迷伤——都写回山里生存循环。 |

**文风样本**：

> 雾从涧底往上漫，漫到集市的檐口就停了。山里人说，雾停在哪里，哪里就是今天的天。
>
> 把头把秤压了压，又抬起来看你：“四十斤。涧口到矿村，一趟脚钱十二文，雾里翻倍——但雾里的路，得你自己记。”
>
> 盐仓的老倌往灶里添了根柴：“官府要收盐引咧。”没人接话。雾贴着窗纸，白得像一层新糊的账。

## 选歪与打磨流程（票面交付的模板）

1. **选歪**：三套中选定一套（或指定两套杂交，注明取哪几件）。
2. **逐段打磨**：对选定套逐节反应——每节（县城/门派/身份链/属性/张力/开场/地点/人物/文风）可单独驳回重写，直到满意。
3. **定稿锚定物**：定稿后整理为正式设定文档（地点表、身份链、属性体系、具名人物原型、文风样本五件），锚定后续票据的词汇表（017）与不变量（016）。
