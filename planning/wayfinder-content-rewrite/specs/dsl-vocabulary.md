# 故事 DSL 谓词与效果词表

- 对应票据：[定义 DSL 谓词与效果词汇表](https://github.com/mnikn/text-wuxia/issues/19)（HITL 逐轮拷问确认，2026-09-15）
- 上游：[#16 书写面与编译器契约](https://github.com/mnikn/text-wuxia/issues/16)、[#22 涌现表达](https://github.com/mnikn/text-wuxia/issues/22)、[#18 属性体系](https://github.com/mnikn/text-wuxia/issues/18)、[世界观种子 v3](../prototypes/worldview-seed-v3.md)
- 本文档是**书写面的唯一词汇表**：内容侧与 AI 起草都只能使用这里登记的谓词与效果条目。编译器校验门按第 5、6 节实现。
- 完整书写面语法（宏集、参数规则、头部两段分工）见 #16；本文档只定「词」。

## 1. 标识符与命名

**书写面标识符一律中文**：地点、人物、物品、属性、武学、池 id、槽位名、helper 名、`tune.` 键、命名空间段。拉丁名只存在于引擎内部符号，不进书写面。

| 形态 | 归属 | 例 |
| --- | --- | --- |
| 无点裸名 | **内建字段白名单**（引擎拥有，见第 6 节） | `hour` `weather` `role` `money` `stamina` |
| 有点裸名 | **内容命名空间**（内容侧注册，见第 7 节） | `mother.arrears` `job.escortSigned` `npc.婆子.好感` |
| 具名函数 | 封闭谓词/效果词汇表（第 2、3 节） | `at("牙市")` `rel("周管事")` `art("苍岩剑法")` |

内建字段与内容命名空间**共用一套名字解析**：同一个名字在谓词里读、在效果条目里写，不设「只读名」「可写名」两套。可写性由注册表里的**权限位**决定（第 6 节）。

## 2. 谓词表

用于 `<<when>>`、选项 `if=`、正文 `<<if>>`、插值 `<<=>>`、槽位 `where`。

| 类 | 形态 | 例 | 说明 |
| --- | --- | --- | --- |
| 内建字段 | 裸名（无点） | `hour >= 18` / `weather == "细雨"` | 白名单闭合，见第 6 节 |
| 剧情标记 / 一等领域 | 裸名（有点） | `!job.escortSigned` / `mother.arrears > 0` | 命名空间注册 |
| 地点 | `at(地点…)` | `at("牙市", "南门贫巷")` | 当前地点 ∈ 实参列表 |
| 天赋 | `tal(天赋)` | `tal("福缘") >= 7` | 五项：膂力/身法/悟性/根骨/福缘 |
| 武学 | `martial(武学)` | `martial("拳脚") >= 40` | 实际武学值 |
| 生活能力 | `cap(能力标签)` | `cap("识药")` | 确定性标签，有即真 |
| 关系 | `rel(具名人物)` | `rel("周管事") >= 3` | 数值比较 |
| 物品 | `item(物品)` | `item("药材") >= 2` | 数量比较 |
| 进度 | `seen(单元 id)` | `seen("牙市.招工.搬货")` | 该单元是否触发过 |
| 素材约束 | `has` / `has any` / `here` | `locs has here` / `tags has any [市井, 乱源]` | 仅 `where` 内；字段名单随素材池形态注册（#22 留实现期） |

**组合子**：`&&` `||` `!` `( )` `==` `!=` `<` `<=` `>` `>=` `in`。

**谓词层的禁止项**：算术、三目、`<<do>>` helper 调用、赋值。同一个判断重复出现三次以上 → 升格为词表里的具名谓词（升格是显式动作，须改本表与编译器）。

## 3. 效果条目表

用于 `<<eff 条目, 条目>>`。条目形态 `<目标> <量>`；量的合法形态只有四类：**字面量 | 单元局部常量 | `tune.` 键 | 具名 helper 调用**，禁裸算术（#16）。

| 目标 | 形态 | 例 |
| --- | --- | --- |
| 银钱 | `money ±量` | `money +30` / `money -tune.饭钱` / `money +工钱("码头", 2)` |
| 体力 / 内力 | `stamina ±量` / `neili ±量` | `stamina -15` |
| 天赋 | — | **不可写**：先天天赋创建时定死 |
| 武学经验 | `art(具体武学) ±量` / `basic(门类基本功) ±量` | `art("苍岩剑法") +12` / `basic("拳脚") +8` |
| 生活能力 | `cap(能力标签)` | `cap("识药")`（升级链自行声明 replaces，只留最高标签） |
| 物品 | `item(物品) ±量` | `item("药材") +1` |
| 装备 | `equip(物品)` | `equip("青钢剑")` |
| 关系 | `rel(具名人物) ±量` | `rel("周管事") +1` |
| 身份 | `role = 身份` | `role = "别院学徒"` |
| 剧情标记 | `命名空间.键 = 值` / `±量` | `job.escortSigned = true` / `mother.arrears +50` |
| 母亲线 | `mother.欠款/到期` | `mother.arrears +50` |
| 线索 | `clue(线索 id)` | `clue("腰牌记号")` |
| 日志 | `log("文本")` | `log("你记下了这张脸")` |
| 伤势 / 生存 / 战斗 | **留空位** | 生存三条资源（体力 / 三层生命 / 双层内力）与战斗读数的条目名与语义由 [#24](https://github.com/mnikn/text-wuxia/issues/24)（生存状态）、[#23](https://github.com/mnikn/text-wuxia/issues/23)（战斗）收口；**身体状态标签本阶段不定义**，不增表行；形状不变 |

**代价条目**（`cost="…"`）是效果条目表的**可支付子集**：`money` / `stamina` / `neili` / `item(…)`，串内省略负号（`cost="time 30, money 12, stamina 10"`）；`time` 是代价串保留字，走 `elapsed` 时间推进，**不是**效果条目、永不「不足」。

**读数值、写正文**：条目的数值只登记机械上被读写的部分。感官与情节的呈现（母亲病情的轻重、伤情的描述、天气的感受）写进正文文字，靠谓词分支表达，不另设状态字段——`mother.arrears` 是数值，正文里按它分支写出病情即可，不需要 `mother.stage`。

**已删条目**：`proof`（入门三证明）随 #18 删除；旧饥饿/疲劳/伤势条目随 #24 重开，不在本表预设保留。

**已延后条目**：身体状态标签（受寒 / 生病 / 中毒这类临时状态）本阶段不定义——引擎侧先只维护体力 / 三层生命 / 双层内力三条资源，[#24](https://github.com/mnikn/text-wuxia/issues/24) 留待后续拓展。内容侧现在不得写任何标签名（白名单里没有，解析不到即 error），标签的读写条目与素材池相关 lint 一并延后。

## 4. 检定

形态 `check="能力 难度"`，**两条标尺**、不做混检：

| 检定 | 例 | 读取 | 量纲 |
| --- | --- | --- | --- |
| 天赋检定 | `check="身法 6"` | 该天赋值 | 1～10，难度约 5～12 |
| 门类检定 | `check="拳脚 45"` | 该门类基本功熟练度 | 0～100 |
| 具体武学检定 | `check="苍岩剑法 45"` | 该具体武学实际值（含基本功加成） | 0～100 |

- **生活技能不检定**（#18：确定性解锁与分支，不掷骰）。
- **档带沿用差值 ±20 缺省**：差值 ≥+20 大成功 / ≥0 成功 / >-20 失败 / ≤-20 大失败；`great=`/`fail=` 可覆盖。
- **`check=` 是唯一掷骰位置**：守卫、插值、`where` 一律只读，不抽 RNG。
- **7 档梯**是显示层派生（`checkHint`），措辞与阈值归 [#20](https://github.com/mnikn/text-wuxia/issues/20) 校准，不是持久状态。

## 5. 受限表达式子集与校验门

### 允许 / 禁止

| 项 | 裁定 |
| --- | --- |
| 算术（谓词与插值） | **禁**。复合量新增具名谓词，不写 `tal("身法") + martial("拳脚") > 50` |
| 三目 | **禁**。分支走 `<<if>>` / `<<choice>>` / `<<band>>` |
| 效果条目的量 | **禁裸算术**。只有字面量 / 局部常量 / `tune.` 键 / 具名 helper |
| 成员访问 | **允许任意链**（`sect.leader.title`、`thug.name`、`master.tags`），语义见下 |
| `<<do>>` helper | 只允许出现在**效果条目的量与插值**；**禁**进入 `<<when>>` / `if=` / `<<if>>` / `where` |
| 自由 JS、`eval` | 全禁（#15/#16）。复杂逻辑走注册的具名纯 helper |

### 任意对象链的语义（校验分层）

- **构建期**：根标识符必须注册；**首段路径**必须注册（`npc.boots.tags` 里 `npc` 与 `boots` 都要在注册表里）；更深段不校验。类型不匹配（字符串比数字等）在可校验到的层级报 error。
- **运行时**：缺失路径 → **dev 期报错**（编译/运行诊断可见），**生产期静默**（谓词取 false、插值取空串）。
- 理由：内容侧起草零报备负担（写法与「全放行」相同），但打错字在开发期就会现形，不走「静默为假」那条最难查的路。

### 校验门（本票补充项，接 #16 的 error/warning 清单）

**error（阻断构建）**：无点裸名不在内建白名单；有点裸名的命名空间未注册；谓词/效果函数未注册；对不可写名字赋值（`hour = 8`）；`where` 里的裸标识符不在素材池字段注册表且不是 `here`；链式取值的根或首段未注册；类型不匹配；`where` 后声明槽位引用未声明槽位；谓词里出现算术、三目或 `<<do>>` helper。

**warning**：同一具名谓词复用达到三次（提示升格进词表，第 2 节）；效果条目的量出现裸数字而正文同段有同值字面量（#16 既有项）。

## 6. 内建字段白名单与增补机制

白名单是**引擎侧单一权威表**，每条登记：字段名、类型、权限（只读 / 可写）、归属、说明。

**当前全表**（**待补**：生存三条资源里的生命值（当前 / 伤势上限 / 最大生命）尚无字段名与权限位，`stamina` / `neili` 只有名字、权限位待核定——生存规则已于 [#24](https://github.com/mnikn/text-wuxia/issues/24) 冻结，字段随可玩原型逐步加属性时按需登记；登记前内容侧写不出「扣生命」这类效果）：

| 字段 | 类型 | 权限 | 说明 |
| --- | --- | --- | --- |
| `hour` | 数值 | 只读 | 当前时辰（0～23） |
| `day` | 数值 | 只读 | 开局至今天数 |
| `weather` | 枚举 | 只读 | 天气值列表待 #20 定稿 |
| `role` | 枚举 | 可写 | 白身 / 别院学徒 / 记名弟子 |
| `money` | 数值 | 可写 | 文 |
| `stamina` | 数值 | 可写 | 体力 |
| `neili` | 数值 | 可写 | 内力 |

**增补机制（可控性）**：

1. **内容侧不得新增无点裸名**——解析不到即 error。内建字段的增长只能由引擎侧改这张表，属代码改动，走评审。
2. 内容想表达新概念 → 走**内容命名空间**（有点），内容侧自行注册，不污染白名单。
3. **增补时必须一次给全**：字段名 + 类型 + 权限 + 归属 + 说明；类型缺了第 5 节的类型校验就退化成运行时。
4. **权限位是硬门**：写一个只读名（`hour = 8`）→ error；只读字段想改，只能由引擎的派生/结算逻辑改。
5. **归属票**：生存状态字段（饥饿/疲劳/伤势类）由 [#24](https://github.com/mnikn/text-wuxia/issues/24) 一次性注册；战斗读数（若需暴露）由 [#23](https://github.com/mnikn/text-wuxia/issues/23) 注册；两票各自增开新表行，不改本节的机制。
6. 每次增补的验收 = 类型表更新 + 校验门跑通 + 一条能读出该字段的样本单元。

## 7. 内容命名空间

规则：命名空间在内容侧注册（前缀白名单），注册后其下的键可读可写；**写入未注册命名空间 → error**（沿用 #16 校验门）。

首批建议清单（[#20](https://github.com/mnikn/text-wuxia/issues/20) 首批内容落地时可增补）：

| 命名空间 | 归属 | 例 |
| --- | --- | --- |
| `mother.*` | 母亲线：欠款、下次药钱到期（病情的轻重不设常驻状态，只由正文文字表达） | `mother.arrears` / `mother.due` |
| `job.*` | 差事线：报名、在途、交付 | `job.escortSigned` |
| `sect.*` | 苍岩派：身份推进、师承、行止具结 | `sect.保人已荐` |
| `npc.*` | 具名人物个体的持久标记与好感 | `npc.周管事.引荐` |
| `world.*` | 世界状态与地点解锁 | `world.黑市已开` |
| `life.*` | 日常与出身残留标记 | `life.出身.农家` |

## 8. AI 起草模板

### 8.1 提示词骨架

```
【角色】你在为武侠江湖生活模拟器起草一个内容单元。

【词表约束】只能使用 planning/wayfinder-content-rewrite/specs/dsl-vocabulary.md
登记的谓词、效果条目、检定与内建字段名。表里没有的一律不许写，
需要新词就停下来说明用途，不要自造。

【硬约束】
- 头部两段：`:: 单元 id [标签]` + `{JSON}`（纯字面量调度元数据）
- 判断只进 <<when>> / if= / <<if>>；禁算术、禁三目、禁自由 JS
- 状态写入只走 <<eff>>；数值两层：单元内用 <<const>>，跨单元用 tune.
- 摘要、耗时、代价一律由引擎派生，正文不手写
- 一个 passage 一个单元；后续单元用 <<next>> 显式链接；涌现模板禁 <<next>>
- 文风：金庸腔，短句、白描、少形容词（样本见世界观种子 v3 第 10 节）

【输入】
- 地点 / 时间窗：
- 事件三分法归属：后果型（有后续）/ 原子性（无后续）/ 纯氛围（无选项）
- 参与人物与前置状态：
- 期望后果（状态变化、是否推进剧情链）：
- 时长与代价：

【输出】一个 passage 的完整 Twee 草稿 + 三行说明：用到的新概念（若有）、
对主线的读写、想让人确认的取舍点。
```

### 8.2 正例

```twee
:: 牙市.招工.搬货 [story]
{"weight": 8, "cooldown": 240}

<<when>>at("牙市") && hour >= 6 && hour <= 18 && !job.escortSigned && money < 200<</when>>

<<const 工钱 = 40>>
牙市婆蹲在檐下嗑瓜子，眼一抬：「后生，扛得动麻袋不？」

<<choice id="take" label="应下这趟活" cost="time 120, stamina 15" if=money < 30 reason="身上还有余钱，不急这一趟">
  <<eff money +工钱, stamina -15>>
  两个时辰下来，肩上磨出一片红印。婆子扔过一串钱：「数清楚了。」
<</choice>>
<<choice id="ask" label="问一句是谁家的货" cost="time 5">
  <<eff npc.婆子.好感 +1>>
  她瞥你一眼：「问得细。街东货栈的，你要去？」
<</choice>>
```

要点：内建字段裸名、内容 flag 带点、时间走 `cost` 不写 `minutes`、数值进 `<<const>>`、`if=` 必带 `reason=`、无 `<<next>>` 即原子性收束。

```twee
:: t.街面.纠缠 [template]
{"weight": 6, "cooldown": 180}

<<when>>at("南门贫巷", "牙市") && !job.escortSigned && weather != "细雨"<</when>>
<<bind slot="泼皮" from="市井人物" where="tags has any [市井, 乱源]">>
<<bind slot="由头" from="纠缠由头">>

<<= 泼皮.name >>从人堆里晃出来，<<= 由头.text >>。
周围行人眼观鼻、鼻观心，绕着走开。
<<choice id="pay" label="给钱息事" cost="time 5, money 8">
  <<eff money -8>>
  你摸出八文钱递过去。他掂了掂，啐了一口，总算让开路。
<</choice>>
```

要点：槽位名与池 id 中文；`where` 用 `has any` + 素材字段；模板 priority 固定第 4 层不写进 JSON；模板无 `<<next>>`。

### 8.3 反例（穿帮清单）

| 反例 | 违规 | 改法 |
| --- | --- | --- |
| `<<when>>tal("身法") + tal("膂力") > 12<</when>>` | 谓词里算术 | 新增具名谓词或改成两项分别比较 |
| `<<when>>hunger >= 70<</when>>` | `hunger` 未注册进白名单 | 等 #24 注册生存字段 |
| `<<= money >= 30 ? "够" : "不够" >>` | 三目 | `<<if money >= 30>>…<<else>>…<</if>>` |
| `<<eff money +30 * 2>>` | 效果量裸算术 | `<<const 赏钱 = 60>>` 或用 helper |
| `<<eff hour = 8>>` | 对只读内建字段赋值 | 时间推进走 `cost="time …"` |
| `<<when>>canAffordMedicine()<</when>>` | helper 进谓词 | 升格成具名谓词，或写进 `if=` 并用效果 helper |
| `<<when>>escrotSigned<</when>>` | 打错字（未注册根） | 构建期 error，改回 `job.escortSigned` |
| `check="识药 40"` | 生活技能不检定 | 改为确定性分支：`<<if cap("识药")>>` |
| `<<when>>proof martial<</when>>` | `proof` 已随 #18 删除 | 改用身份/能力标签/关系谓词 |
