# MVP 里程碑计划

依赖链：M0 → M1 → {M2, M3} → M4 → M5 → M6 → M7 → M8（M2/M3 可互换顺序，其余串行）。
M3 验收后内容生产按内容管线持续并行；里程碑只按范围与退出条件定义，不含时间估计。

---

## M0 工程脚手架

- **可演示交付物**：手机"添加到主屏"打开空白 PWA 壳；CI 绿灯截图。
- **测试要求**：构建链冒烟测试（Tweego + Vite + TypeScript 全链路）。
- **退出条件**：构建链跑通，CI 绿，PWA 空白壳可在手机主屏启动。
- **下游依赖**：解锁 M1。
- **关联票据**：001-verify-technical-foundation。

## M1 事务核心

- **可演示交付物**：脚本提交一段行动序列并回放，展示确定性结果。
- **测试要求**：单测覆盖确定性（同快照+种子两次执行逐字节一致）、事务回滚、调度顺序。
- **退出条件**：GameState / 行动管线 / 确定性 RNG / 时钟调度实现且单测全绿。
- **下游依赖**：解锁 M2、M4、M5。
- **关联票据**：003-define-state-and-action-transaction。

## M2 交互壳与渲染

- **可演示交付物**：手机上操作方案 D 壳（胶囊导航、抽屉页签），渲染示例 passage 与 logline。
- **测试要求**：人审验收（交互与移动端修边）。
- **退出条件**：方案 D 壳在手机上可操作；SugarCube 只读渲染接通；logline 嵌入正文流。
- **下游依赖**：解锁 M6 的演示面。
- **关联票据**：005-define-mobile-interface。

## M3 故事管线

- **可演示交付物**：一个示例故事单元从 Twee 源码走到可玩（入口评估 → 正文 → 选择 → 结算）。
- **测试要求**：构建期校验门用例（schema / 引用 / 写宏 lint / 命名约定）。
- **退出条件**：宏提取器 + 故事注册表 + 入口评估可用；构建期校验门生效。
- **下游依赖**：解锁内容并行生产（009 管线），支撑 M4、M6。
- **关联票据**：006-design-event-dsl、009-design-content-pipeline。

## M4 生活循环

- **可演示交付物**：连续三日生活循环（打工 / 吃饭 / 训练 / 死线推进）可玩。
- **测试要求**：数值不变量单测（时薪上限、成长递减、维护税），常量来自 balance.ts。
- **退出条件**：三维 / 打工 / 采集 / 训练 / 死线调度可玩；balance.ts 常量接入。
- **下游依赖**：支撑 M6。
- **关联票据**：002-define-vertical-slice、008-balance-progression-and-economy。

## M5 战斗

- **可演示交付物**：一场伏击战可玩，胜利 / 逃跑 / 战败 / 被擒四结局可达并写回生活循环。
- **测试要求**：回合事务单测 + 检定档带断言。
- **退出条件**：回合事务 + 伤势 + 四结局写回实现；战斗复用检定档带。
- **下游依赖**：支撑 M6。
- **关联票据**：004-define-combat-loop。

## M6 护送切片内容

- **可演示交付物**：完整试玩路径（角色创建 → 县城落脚 → 护送 → 四级结果入门收束）。
- **测试要求**：内容校验门全绿（构建期 + CI：可达性、黄金场景回放、注册表 diff）。
- **退出条件**：护送链 8～12 节点 + 环境与生活单元 12～18 + 两成两败结局收束全部入库。
- **下游依赖**：解锁 M8。
- **关联票据**：002-define-vertical-slice、009-design-content-pipeline。

## M7 存档

- **可演示交付物**：自动档 / 手动槽 / 损坏回退 / 导出导入全流程演示。
- **测试要求**：存档层 Node 无头单测（双缓冲原子写、校验、迁移链占位）。
- **退出条件**：双缓冲 + 自动档 + 3 手动槽 + 导出导入可用；损坏回退可演示。
- **下游依赖**：解锁 M8。
- **关联票据**：007-design-save-contract。

## M8 打磨与验收

- **可演示交付物**：模拟器 margin 报告、真机验收记录、试玩版发布包。
- **测试要求**：模拟器四 bot 全绿（训练 / 打工 / 均衡 margin ≤4h / 摆烂不软锁）；性能预算达标。
- **退出条件**：性能预算（首屏 ≤3s / 行动 ≤100ms / 初始包 ≤2MB gzip）达标；真机验收通过；单 HTML 试玩版发布。
- **下游依赖**：解锁公开试玩与反馈收集。
- **关联票据**：008-balance-progression-and-economy、001-verify-technical-foundation。

## MVP 后路线图（低精度，只定方向与先后）

1. **单 HTML（itch.io）发行先行** → Android APK → 桌面发行最后。
2. 试玩反馈收集 → 内容储备期（特殊武学 / 特殊招式、多敌人）→ 跨周目元进度。
