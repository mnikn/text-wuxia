# 遗物剑取「当」不取「卖断」

开场里父亲留下的剑是玩家唯一的资产，当铺给一两。我们选了**当**：可赎、有当票、三个月不来赎就归柜上。理由是赎期把遗物变成一条天生的长期目标——一两是今天的药钱和粮钱，赎回它是往后的事。卖断更干净，但一出场就把父亲这条线彻底清掉，以后再想接就接不回来了。

## Considered Options

- **卖断**：一手交钱一手清，不用当票，没有后续。开局最省事，代价是遗物在开场五分钟内被永久消耗。
- **当**（选中）：文案里留当票与三个月期限，作为长期目标的钩子，不占本批工作量。

## Consequences

- 「剑已当」这个事实**目前记不进存档**：引擎的身体与日常状态只有体力 / 三层生命 / 双层内力 / 时间地点银钱，没有 flags 也没有物品栏。当票在开场里只是文字，赎回剧情要等状态层接上才能做。
- 后续真要做赎回线时，截止时间压力是现成的（三个月），不必另造一个世界定时事项。
